# hover-host 全站收敛：位移的 :hover 一律挂到不动的宿主上

## 原理（抖动根因）

`hover:-translate-y` 直接写在移动元素上：指针停在元素底边 2~3px 带内时，元素上移→指针移出→hover 断→回落→指针又进入→无限横跳。`.hover-host` 模型（tokens.css 已有）：宿主盒子不动、承接 ：hover，子元素 `.hoverable-shadow` 接收位移与影子换档——命中区恒定，无抖动。

## tokens.css（交互模型收口）

- **保留并补全 host 规则**：现有 `shadow-ink` / `drop-shadow-ink` 两档之外，新增 `shadow-btn`（-2px＋5px 实影）、`shadow-btn-ring`（-2px＋inset 2px＋5px）、`lift-sm`（-2px 不换影，便签用），以及 `.hover-host:hover .ticket-lift .ticket-shadow`（Ticket 内层轮廓影换档）；
- **删除直接 ：hover 危险规则**：`.hoverable-shadow:hover` 系列（含重复定义的两条）与 `.ticket-lift:hover` 全部退场——系统只提供安全路径，反例由 design-shadow 页用内联 tailwind 类演示；
- **新增 reduced-motion 全局豁免**：`@media (prefers-reduced-motion: reduce)` 下宿主触发的位移归零（替代各组件散落的 motion-reduce 类）。

## 组件改造（9 处自 hover → host 触发）

| 组件 | 改法 |
|---|---|
| ShadowButton（全站，含 playground 运行键） | 包一层 `hover-host inline-flex`；子元素加 `hoverable-shadow shadow-btn`（active 变体 `shadow-btn-ring`）；删 SHADOW_BUTTON_HOVER/RING_HOVER；transition 补 translate |
| Button | 包 `hover-host inline-block`；子加 `hoverable-shadow`（rest 已是 shadow-ink，零新 CSS）；删 hover:* |
| ShadowCard | 包 `hover-host block w-fit`；外层加 `hoverable-shadow`；ticket 分支由 Ticket 内部处理 |
| Ticket / ChapterTicket | 组件内自包 host；壳加 `hoverable-shadow`；tokens 按 ticket-lift 换内层影 |
| RoutableCard | 外层定位 div 兼任 host（加 `hover-host`）；`<a>` 加 `hoverable-shadow` 删 hover:*（MemphisCard 分支同被覆盖） |
| MemphisCard | 删 hover:*（host 由 RoutableCard 外层提供）；focus-visible 位移保留（键盘焦点不依赖指针，无抖动） |
| CoachSticky（陪练便签） | 按钮外包 `hover-host block`（只裹按钮不裹面板）；按钮加 `hoverable-shadow lift-sm`；motion-reduce 交给全局豁免 |
| BlogPages 博客卡 / design 五册卡 | 包 `hover-host block w-fit`；子加 `hoverable-shadow` 删 hover:* |

若 MemphisCard 存在 RoutableCard 之外的独立使用点，则组件内自包 host（实现时 grep 确认）。

## design-shadow 新增「触发模型 · hover-host」章节（页面末尾）

DoDont 对比：反例＝自 hover（内联 tailwind hover:-translate 演示，文案点明底边抖动）；正例＝hover-host（宿主承接、子元素位移）。再加一行变体全家福：按钮档（shadow-btn）、撕角档（drop-shadow-ink）、便签档（lift-sm）各自 host＋hoverable-shadow，展示同一套约定。放在页面末尾，不干扰既有 `pages.spec` 的 `.hover-host` first() 断言。
